## 1. 消息格式概览

完整消息格式示例：

```
<content>
[[character||角色名：白娅||场景：教室||台词：今天天气真好呢~]]
[[narration||旁白：她走进了教室]]
[[choice||去图书馆||去食堂]]
</content>

<dm>弹幕1|弹幕2|弹幕3</dm>

<background>
title###教室###
image###classroom, daylight, window###
</background>
```

## 2. 对话块格式

### 2.1 基本格式

```
[[character||角色名：xxx||场景：xxx||台词：xxx]]
```

### 2.2 完整字段

```
[[character||角色名：白娅||场景：教室||动作：叹气||表情：微笑||台词：今天天气真好呢~]]
```

| 字段 | 键名 | 说明 | 示例 |
|------|------|------|------|
| 角色名 | `角色名` / `角色` | 角色显示名称 | `白娅` |
| 场景 | `场景` | 背景场景名 | `教室` |
| 动作 | `动作` | Live2D 动作关键词 | `叹气` |
| 表情 | `表情` | Live2D 表情关键词 | `微笑` |
| CG场景 | `CG场景` | CG 场景名（优先级高于场景） | `教室CG` |
| 台词 | `台词` | 对话内容 | `今天天气真好呢~` |

### 2.3 正则表达式

```typescript
// 匹配 [[...]] 块
const BLOCK_REGEX = /\[\[([^\]]+)\]\]/g;

// 匹配 character 类型
const CHARACTER_REGEX = /\[\[character\s*\|\|([^\]]+)\]\]/gi;

// 提取键值对（支持 || 分隔和冒号键值）
const PAIRS_REGEX = /([^：:]+)[：:]([^||]+)/g;
```

### 2.4 解析函数

```typescript
interface ParseCharacterBlockOptions {
  character?: string;  // 角色名
  scene?: string;      // 场景
  motion?: string;    // 动作
  expression?: string; // 表情
  text?: string;      // 台词
  isCG?: boolean;     // 是否 CG
  cgScene?: string;   // CG 场景名
}

/**
 * 解析 character 块
 * @param blockText 原始块文本，如 "character||角色名：白娅||场景：教室||台词：xxx"
 * @returns 解析后的字段对象
 */
function parseCharacterBlock(blockText: string): ParseCharacterBlockOptions;
```

```
[[narration||旁白：她走进了教室]]
```

### 3.2 完整字段

```

```

| 字段 | 键名 | 说明 |
|------|------|------|
| 场景 | `场景` | 背景场景名（可选） |
| 旁白 | `旁白` | 叙述内容 |

### 3.3 正则表达式

```typescript
// 匹配 narration 类型
const NARRATION_REGEX = /\[\[narration\s*\|\|([^\]]+)\]\]/gi;
```

### 3.4 解析函数

```typescript
interface ParseNarrationBlockOptions {
  scene?: string;   // 场景
  message?: string; // 旁白内容
}

/**
 * 解析 narration 块
 */
function parseNarrationBlock(blockText: string): ParseNarrationBlockOptions;
```

## 4. 黑屏转场格式

### 4.1 基本格式

```
[[blacktext||黑屏文字：xxx]]
```

### 4.2 备选字段名

系统支持多种字段名，自动兼容：

| 字段 | 键名（按优先级） |
|------|-----------------|
| 黑屏文字 | `黑屏文字` |
| 台词内容 | `台词内容` |
| 台词 | `台词` |
| 文字 | `文字` |
| text | `text` |

### 4.3 正则表达式

```typescript
// 匹配 blacktext 类型（支持多种别名）
const BLACKTEXT_REGEX = /\[\[blacktext\s*\|\|([^\]]+)\]\]/gi;
// 别名：black、black_screen、black-screen、黑屏、黑屏文字、黑幕、黑幕文字
```

### 4.4 解析函数

```typescript
interface ParseBlacktextBlockOptions {
  message?: string; // 黑屏文字内容
}

/**
 * 解析 blacktext 块
 */
function parseBlacktextBlock(blockText: string): ParseBlacktextBlockOptions;
```

## 5. 选择框格式

### 5.1 基本格式

```
[[choice||选项1||选项2||选项3]]
```

### 5.2 带标签格式

```
[[choice||选项1：去图书馆||选项2：去食堂||选项3：自由输入]]
```

### 5.3 正则表达式

```typescript
// 匹配 choice 类型
const CHOICE_REGEX = /\[\[choice\s*\|\|([^\]]+)\]\]/gi;

// 匹配选项（支持 "选项X：" 或纯选项名格式）
const OPTION_REGEX = /(?:选项\d+[：:]\s*)?([^||]+)/g;
```

### 5.4 解析函数

```typescript
interface ParseChoiceBlockOptions {
  options: string[]; // 选项列表
}

/**
 * 解析 choice 块
 */
function parseChoiceBlock(blockText: string): ParseChoiceBlockOptions;
```

### 5.5 示例

```typescript
// 输入: "choice||去图书馆||去食堂||选项3：自由输入"
// 输出: { options: ['去图书馆', '去食堂', '自由输入'] }
```

## 6. 弹幕格式

### 6.1 基本格式

```
<dm>弹幕1|弹幕2|弹幕3</dm>
```

### 6.2 带颜色格式

```
<dm color="red">弹幕1|弹幕2|弹幕3</dm>
```

### 6.3 正则表达式

```typescript
// 基础弹幕标签
const DANMAKU_REGEX = /<dm[^>]*>([\s\S]*?)<\/dm>/gi;

// 提取颜色（可选）
const DANMAKU_COLOR_REGEX = /color=["']?([^"'\s>]+)["']?/;
```

### 6.4 解析函数

```typescript
interface DanmakuItem {
  text: string;     // 弹幕文本
  color?: string;   // 颜色（可选，默认白色）
}

/**
 * 解析弹幕块
 * @param message 包含弹幕的消息文本
 * @returns 弹幕文本数组
 */
function extractDanmakuBlock(message: string): string[];

/**
 * 解析弹幕文本数组为 DanmakuItem 列表
 * @param texts 弹幕文本数组（已按 | 分隔）
 * @param defaultColor 默认颜色
 * @returns DanmakuItem 数组
 */
function parseDanmakuItems(texts: string[], defaultColor?: string): DanmakuItem[];
```

## 7. 生图标签格式

### 7.1 背景格式

```
<background>
title###场景名###
image###生图提示词（英文，逗号分隔）###
</background>
```

### 7.2 CG 格式

```
<cg>
title###场景名###
image###生图提示词###
</cg>
```

### 7.3 字段说明

| 字段 | 格式 | 说明 |
|------|------|------|
| title | `title###xxx###` | 叙事锚点，用于匹配 |
| image | `image###xxx###` | 生图提示词（英文） |

### 7.4 正则表达式

```typescript
// 匹配 background 或 cg 标签
const IMAGE_TAG_REGEX = /<(background|image)>([\s\S]*?)<\/\1\s*>/gi;

// 提取 title
const TITLE_REGEX = /title###([\s\S]*?)###/i;

// 提取 image/prompt
const PROMPT_REGEX = /image###([\s\S]*?)###/i;
```

### 7.5 解析函数

```typescript
interface ImageTagBlock {
  type: 'background' | 'cg';
  title: string;
  prompt: string;
}

/**
 * 提取所有生图标签块
 * @param message 消息文本
 * @returns ImageTagBlock 数组
 */
function extractImageTagBlocks(message: string): ImageTagBlock[];
```

## 8. 足迹格式

### 8.1 基本格式

```
【足迹：（☀️）标题|触发条件：xxx|奖励：xxx|评价："xxx"】
```

### 8.2 正则表达式

```typescript
const FOOTPRINT_REGEX = /\*{0,2}【\s*(?:触发)?成就[^：:|｜]*?[：:|｜]\s*[（(]?\s*([^\s)）|｜】]{1,3})\s*[)）]?\s*([^|｜】]*?)\s*[|｜]\s*(?:触发)?(?:条件)?[：:]?\s*([\s\S]*?)\s*[|｜]\s*(?:奖励)?[：:]?\s*([\s\S]*?)(?:\s*[|｜]\s*(?:系统)?(?:评价)?[：:]?\s*([\s\S]*?))?\s*】\*{0,2}/gu;
```

### 8.3 解析函数

```typescript
interface Footprint {
  icon: string;      // Emoji 图标
  title: string;     // 标题
  condition: string;  // 触发条件
  reward: string;    // 奖励
  evaluation: string; // 评价
}

/**
 * 解析足迹标签
 * @param text 消息文本
 * @returns Footprint 对象或 null
 */
function parseFootprint(text: string): Footprint | null;
```

### 8.4 字段截断规则

| 字段 | 最大长度 | 截断方式 |
|------|----------|----------|
| 标题 | 8 字符 | 尾部截断 |
| 条件 | 15 字符 | 尾部截断 + 省略号 |
| 背景文字 | 25 字符 | 尾部截断 + 省略号 |

## 9. 解析器函数

### 9.1 主解析函数

```typescript
/**
 * 解析消息为 MessageBlock 数组
 *
 * 解析规则：
 * 1. 仅解析 <content>...</content> 标签内的内容
 * 2. 标签内按 [[...]] 格式解析对话块
 * 3. 无格式文本视为旁白
 * 4. 消息块内的换行会自动拆分为多个块
 *
 * @param message 原始消息文本
 * @param lastScene 上一楼的场景（用于场景继承）
 * @param role 消息角色
 * @returns MessageBlock 数组
 */
async function parseMessageBlocks(
  message: string,
  lastScene?: string,
  role: 'assistant' | 'system' | 'user' = 'assistant'
): Promise<MessageBlock[]>;
```

### 9.2 辅助函数

```typescript
/**
 * 从消息中提取 <content>...</content> 标签内的纯文本
 */
function extractPlainTextFromContent(message: string): string;

/**
 * 提取所有弹幕文本
 */
function extractDanmakuBlock(message: string): string[];

/**
 * 提取所有生图标签
 */
function extractImageTagBlocks(message: string): ImageTagBlock[];

/**
 * 模糊匹配场景名
 */
function fuzzyMatchTitle(source: string, target: string): boolean;
```

### 9.3 类型定义

```typescript
interface MessageBlock {
  type: 'character' | 'narration' | 'blacktext' | 'user' | 'choice';

  // character 类型
  character?: string;
  scene?: string;
  motion?: string;
  expression?: string;
  text?: string;
  isCG?: boolean;

  // narration/blacktext/user 类型
  message?: string;

  // choice 类型
  options?: string[];

  // 世界书资源匹配结果
  sceneImageUrl?: string;
  cgImageUrl?: string;
  spriteImageUrl?: string;
  motionFile?: string;
  expressionFile?: string;
}
```
