# galgame-v2 UI 规划文档

## 概述

本文档规划 galgame-v2 的 UI 组件、按钮分布和界面布局。基于现有 galgame-v1 的 UI 结构，保留可用部分，并根据 v2 设计文档的需求进行增删。

**两个主题方向：**
1. **Animal Island 风格** - 使用 animal-island-vue UI 库，圆润卡片、柔和配色、可爱图标
2. **液态玻璃/Linear 风格** - 毛玻璃效果、渐变半透明、简洁线条

## 二、主界面组件

### 2.1 舞台层 (StageArea)

**位置：** 全屏背景，最底层

**包含子组件：**

| 子组件            | 功能                        | 状态    |
| ----------------- | --------------------------- | ------- |
| `BackgroundLayer` | 显示背景图片或默认渐变      | 新增 v2 |
| `SpriteLayer`     | 显示角色立绘（静态/Live2D） | 新增 v2 |
| 暗角效果          | CSS 径向渐变叠加            | 保留    |
| CG层              | 显示生成的 CG 图片          | 保留    |
| `DanmakuLayer`    | 弹幕动画层                  | 保留    |

**默认大气背景设计（无图片时）：**

| 主题          | 风格描述                                       |
| ------------- | ---------------------------------------------- |
| Animal Island | 柔和渐变（浅蓝→粉→橙）、圆润云朵装饰、可爱字体 |
| 液态玻璃      | 动态渐变背景、毛玻璃质感、极简几何装饰         |

---

### 2.2 快捷菜单 (QuickAccessMenu)

**位置：** 左上角 + 右上角

#### 左侧菜单

| 状态   | 显示内容         |
| ------ | ---------------- |
| 收起态 | 单图标按钮 `[👤]` |
| 展开态 | 胶囊按钮列表     |

| 按钮 | 图标         | 功能         | 备注 |
| ---- | ------------ | ------------ | ---- |
| 角色 | `fa-user`    | 打开角色面板 | 保留 |
| 玩法 | `fa-gamepad` | 打开玩法面板 | 保留 |

#### 右侧菜单

| 状态   | 显示内容         |
| ------ | ---------------- |
| 收起态 | 单图标按钮 `[⚙️]` |
| 展开态 | 胶囊按钮列表     |

| 按钮 | 图标                    | 功能         | 备注 |
| ---- | ----------------------- | ------------ | ---- |
| 设置 | `fa-gear`               | 打开设置面板 | 保留 |
| 全屏 | `fa-expand/fa-compress` | 切换全屏     | 保留 |
| 历史 | `fa-book-open`          | 打开历史面板 | 保留 |

**Animal Island 风格按钮样式：**
- 圆角胶囊形按钮
- 柔和边框 + 背景
- 悬停放大 + 阴影
- 图标 + 文字并排

**液态玻璃风格按钮样式：**
- 毛玻璃背景 `backdrop-filter: blur()`
- 细边框 + 半透明
- 悬停发光效果
- 图标为主，文字可选

### 2.3 成就刘海 (AchievementNotch)

**位置：** 顶部中央

| 元素     | 说明               |

**Animal Island 风格：**

**液态玻璃风格：**
- 超薄刘海

- 展开为侧边抽屉

### 2.4 对话框 (DialogueBox)

**位置：** 底部居中

#### 布局结构

```
┌────────────────────────────────────────────────────────────┐
│ [头像]  [名字标签]                                          │
│                                                            │
│                      台词文本区域                           │
│                                                            │
│  [←]                                                   [→] │
└────────────────────────────────────────────────────────────┘
```

#### 包含元素

| 元素     | 说明             | 主题样式      |
| -------- | ---------------- | ------------- |
| 头像     | 用户头像（可选） | 左上角圆形    |
| 名字标签 | 角色名           | 气泡/标签形式 |
| 台词文本 | 带打字机效果     | 可滚动区域    |
| 左箭头   | 上一页           | 左边缘        |
| 右箭头   | 下一页           | 右边缘        |

#### 交互行为

| 交互       | 行为                    |
| ---------- | ----------------------- |
| 点击对话框 | 跳过打字机 / 翻到下一页 |
| 点击左箭头 | 上一页（块级别）        |
| 点击右箭头 | 下一页（块级别）        |
| 键盘 ←/→   | 翻页                    |
| 键盘空格   | 跳过打字机              |
| 键盘 Enter | 翻页（无打字机时）      |

#### 黑屏转场 (BlacktextOverlay)

**触发：** 当前块为 `blacktext` 类型

| 主题          | 样式                           |
| ------------- | ------------------------------ |
| Animal Island | 黑底 + 圆角文字框 + 可爱箭头   |
| 液态玻璃      | 纯黑 + 毛玻璃文字框 + 细线箭头 |

## 六、移动端适配

### 6.1 竖屏模式

竖屏模式主要用于在桌面端模拟手机端显示和测试，实际酒馆助手可能运行在手机浏览器上。

#### 屏幕比例

```typescript
// App.vue - 根据 portraitMode 切换宽高比
const mainStyle = computed(() => {
  if (isPortraitMode.value) {
    return {
      ...base,
      aspectRatio: '3 / 4',  // 竖屏 3:4
    };
  }
  return {
    ...base,
    aspectRatio: '16 / 9',   // 横屏 16:9
  };
});
```

#### 竖屏布局调整

|                    | 元素                      | 横屏                                          | 竖屏 |
| ------------------ | ------------------------- | --------------------------------------------- |
| 对话框宽度         | `100%`（margin 留白）     | `100%`（padding 留白）                        |
| 对话框底部         | `1.5rem`                  | `0.8vmin`                                     |
| 头像位置           | `top: 0.5em; left: 0.5em` | `bottom: calc(16vmin + 3vmin); left: 1.5vmin` |
| 选项框底部         | `11rem`                   | `8rem`                                        |
| 选项框左右 padding | `1rem`                    | `1rem`                                        |

#### CSS 变量覆盖

```css
:root {
  /* 竖屏对话框 */
  --theme-dialogue-bottom-portrait: 0.8vmin;
  --theme-dialogue-portrait-padding-x: 1rem;
  --theme-dialogue-min-height-portrait: 16vmin;

  /* 竖屏头像 */
  --theme-dialogue-portrait-bottom-portrait: calc(16vmin + 3vmin);
  --theme-dialogue-portrait-left-portrait: 1.5vmin;

  /* 竖屏选项 */
  --theme-choice-bottom-portrait: 8rem;
}
```

### 6.2 触摸交互

|            | 交互                                  | 行为 |
| ---------- | ------------------------------------- |
| 点击对话框 | 跳过打字机 / 翻到下一页（与横屏一致） |
| 左滑动手势 | 上一页（块级别）                      |
| 右滑手势   | 下一页（块级别）                      |
| 点击左箭头 | 上一页（块级别）                      |
| 点击右箭头 | 下一页（块级别）                      |

**触摸手势实现**：在 `App.vue` 中监听 `touchstart` / `touchmove` / `touchend` 事件，计算滑动距离和方向，阈值设为 50px。

## 十、楼层懒解析

### 10.1 设计目标

为了提升性能，只解析当前可见楼层及其前后各 2 个楼层，其他楼层保持轻量状态。

### 10.2 解析状态

| 状态          | 说明     | 包含内容                                    |
| ------------- | -------- | ------------------------------------------- |
| `full`        | 完整解析 | 完整的块结构、角色名、文本内容等            |
| `lightweight` | 轻量标记 | 块数量、角色列表、是否有选项/黑屏、预览文本 |
| `unparsed`    | 未解析   | 无内容，等待访问时解析                      |

### 10.3 切换规则

```
初始状态（进入游戏）：
├── 第 0 层：full
├── 第 1 层：full（邻居）
├── 第 2 层：full（邻居）
├── 第 3 层：unparsed
└── 第 N 层：unparsed

用户翻到第 3 层：
├── 第 1 层：lightweight
├── 第 2 层：full
├── 第 3 层：full（当前）
├── 第 4 层：full（邻居）
├── 第 5 层：full（邻居）
└── 其他：unparsed
```

### 10.4 数据结构

```typescript
interface DialogueUnit {
  messageId: number;
  parseState: 'full' | 'lightweight' | 'unparsed';

  // 完整解析时
  blocks?: MessageBlock[];

  // 轻量标记时
  lightweightInfo?: {
    blockCount: number;
    characters: string[];
    hasChoices: boolean;
    hasBlacktext: boolean;
    previewText: string;
  };
}
```

### 10.5 解析器接口

```typescript
interface MessageParser {
  // 完整解析
  parseFull(text: string): MessageBlock[];

  // 轻量解析（快速提取元信息）
  parseLightweight(text: string): LightweightInfo;
}
```

## 十一、足迹系统

### 11.1 设计目标

足迹是一种可以穿插在正文中的收集型卡片，用于记录玩家在游戏中的重要时刻。参考贴纸卡片设计。

### 11.2 消息格式

```
【足迹：（☀️）标题|触发条件：xxx|奖励：xxx|评价："xxx"】
```

**正则表达式：**

```regex
/\*{0,2}【\s*(?:触发)?成就[^：:|｜]*?[：:|｜]\s*[（(]?\s*([^\s)）|｜】]{1,3})\s*[)）]?\s*([^|｜】]*?)\s*[|｜]\s*(?:触发)?(?:条件)?[：:]?\s*([\s\S]*?)\s*[|｜]\s*(?:奖励)?[：:]?\s*([\s\S]*?)(?:\s*[|｜]\s*(?:系统)?(?:评价)?[：:]?\s*([\s\S]*?))?\s*】\*{0,2}/gu
```

**解析字段：**

| 字段 | 示例                  | 说明           |
| ---- | --------------------- | -------------- |
| 图标 | ☀️                     | Emoji          |
| 标题 | 初次相遇              | 显示在贴纸上   |
| 条件 | 初次相遇              | 显示在标题上方 |
| 奖励 | +10                   | 右下角显示     |
| 评价 | "命运的相遇开始了..." | 卡片内文字     |

### 11.3 显示流程

```
消息解析
    ↓
检测到【足迹：...】格式
    ↓
在当前位置渲染遮罩层
    ↓
弹出贴纸卡片（带渐显动画）
    ↓
用户点击任意处
    ↓
卡片淡出 + 遮罩消失
    ↓
继续显示后续内容
```

### 11.4 卡片样式

```
┌────────────────────────────────┐
│  ✦                          ✦  │  ← 装饰星星（浮动动画）
│                                │
│  ┌ 触发条件：初次相遇 ┐      │  ← 条件标签（贴在标题上方）
│  │                          │  │
│  │     ☀️ 初次相遇          │  │  ← 标题 + Emoji（描边效果）
│  │                          │  │

```
