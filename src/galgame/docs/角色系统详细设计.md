本文档用于细化 `src/galgame` 中「角色系统」的变量结构、聊天扫描协议与 LLM 生成提示词，是《玩法-角色与派遣规划.md》的下游文档。

**前置文档**：《玩法-角色与派遣规划.md》、《SystemPrompt模板.md》

> 备注：变量名偏好中文命名（如「姓名」「战力」），解析层负责映射。角色系统采用**聊天扫描 + CMD 协议**形式运作，通过聊天消息中的指令标签实现角色数据的增删改查。

## 2. TypeScript 类型定义

> 位于 `src/galgame/types/role.ts`

> 备注：角色系统采用灵活的键值存储，档案层字段均为可选，用户可随时扩展其他字段。属性由 AI 生成初始值。

```typescript
import { z } from 'zod';

// ============================================================================
// 角色系统 Schema 定义
// ============================================================================

// 属性枚举值（0~5 整数）
const 属性值 = z.number().int().min(0).max(5);

// 属性对象（由 AI 根据定位/性格生成初始值）
const 属性Schema = z.object({
  战力: 属性值.default(0),
  技巧: 属性值.default(0),
  智慧: 属性值.default(0),
  社交: 属性值.default(0),
  谨慎: 属性值.default(0),
  运气: 属性值.default(0),
});

// 角色状态枚举
export const 角色状态枚举 = z.enum([
  '空闲',
  '派遣中',
  '工坊中',
  '逃跑中',
  '休息中',
  '加班中',
  '受伤',
]);
export type 角色状态 = z.infer<typeof 角色状态枚举>;

// 技能效果
const 技能效果Schema = z.object({
  域: z.string(),
  键: z.string(),
  值: z.number(),
});

// 技能标签对象
export const 技能Schema = z
  .object({
    id: z.string(),
    名称: z.string(),
    emoji: z.string().default(''),
    描述: z.string().default(''),
    效果: z.array(技能效果Schema).default([]),
  })
  .prefault({});
export type 技能 = z.infer<typeof 技能Schema>;

// 角色记录条目
const 角色记录条目Schema = z.object({
  时间: z.number(),
  类型: z.enum(['派遣', '工坊', '通讯', '其他']).default('其他'),
  内容: z.string().default(''),
});

// 角色对象
// - 姓名、属性固定必填
// - 其它字段均为可选，支持用户自定义扩展
// - 扫描器解析时使用 catchall 存储任意键值对
export const 角色Schema = z
  .object({
    // ---- 必需字段 ----
    id: z.string(),           // 唯一标识（系统生成）
    姓名: z.string(),        // 固定必填
    属性: 属性Schema,        // 固定必填

    // ---- 预定义可选字段 ----
    外貌: z.string().optional(),
    性格: z.string().optional(),
    出身: z.string().optional(),
    定位: z.string().optional(),
    说话风格: z.string().optional(),
    喜好: z.string().optional(),
    特长: z.string().optional(),
    职业: z.string().optional(),
    背景故事: z.string().optional(),

    // ---- 装备层 ----
    已装备技能: z.array(z.string()).default([]),

    // ---- 状态层 ----
    状态: 角色状态枚举.default('空闲'),
    当前任务: z.string().nullable().default(null),

    // ---- 记录层 ----
    记录: z.array(角色记录条目Schema).default([]),
  })
  .catchall(z.any())  // 允许额外自定义字段（如年龄、背景等）
  .prefault({});
export type 角色 = z.infer<typeof 角色Schema>;

// 扫描检查点
export const 角色检查点Schema = z
  .object({
    message_id: z.number().default(0),
    max_id: z.number().default(0),
    db_map: z.record(z.string(), 角色Schema).default({}),
  })
  .prefault({});
export type 角色检查点 = z.infer<typeof 角色检查点Schema>;

// 角色系统顶层变量
export const 角色系统变量Schema = z
  .object({
    // ---- 扫描管理 ----
    role_db_map: z.record(z.string(), 角色Schema).default({}),
    role_max_id: z.number().default(0),
    role_checkpoint: 角色检查点Schema.default({}),

    // ---- 角色数据 ----
    roles: z.record(z.string(), 角色Schema).default({}),

    // ---- 技能数据 ----
    skillsInventory: z.array(技能Schema).default([]),
    skill_max_id: z.number().default(0),
    skill_db_map: z.record(z.string(), 技能Schema).default({}),

    // ---- 派遣记录 ----
    dispatchRuns: z.array(z.any()).default([]),
  })
  .prefault({});
export type 角色系统变量 = z.infer<typeof 角色系统变量Schema>;
```

### 2.1 设计说明

**与物品栏脚本的对比：**


| 物品栏脚本             | 角色系统                  |
| ----------------- | --------------------- |
| 纯 JavaScript，动态对象 | TypeScript + Zod 类型定义 |
| 任意 key-value 存储   | 固定字段 + 允许额外字段         |
| 扫描时解析为 Map        | 扫描时写入 `roles` 字典      |


**灵活存储的实现：**

```typescript
// 解析时直接存储所有字段
b.replace(/[【】]/g, "").split(/[|｜]/).forEach(p => {
  var arr = p.split(/[:：]/);
  if (arr.length >= 2) r[arr[0].trim()] = arr.slice(1).join(':').trim();
});

// 角色系统的做法：Zod Schema + catchall 允许额外字段
export const 角色Schema = z
  .object({
    id: z.string(),
    姓名: z.string(),
    外貌: z.string().optional(),
    性格: z.string().optional(),
    // ... 固定字段
  })
  .catchall(z.any())  // 允许任意额外字段
  .prefault({});
```

这样 AI 在 CMD 中生成的任何符合格式的字段都会被正确存储到聊天变量中。

## 3. CMD 协议（聊天扫描指令）

角色系统通过监听聊天消息中的 `CMD` 指令标签实现数据的增删改查，与物品栏脚本机制一致。

### 3.1 角色相关 CMD

#### 3.1.1 CMD:ADD — 创建角色

```
<Character>
CMD:ADD | 键1:值1 | 键2:值2 | ...
</Character>
```


| 字段   | 说明                                       |
| ---- | ---------------------------------------- |
| 姓名   | 固定必填，角色姓名                                |
| 属性   | 固定必填，格式为 `战力:3/技巧:2/智慧:1/社交:2/谨慎:1/运气:0` |
| 其它字段 | 可选，如外貌、性格、出身、定位、说话风格、喜好、特长、职业等           |


> 支持任意键:值格式，扫描器解析后直接写入角色对象。用户可扩展自定义字段。

示例：

```
<Character>
CMD:ADD | 姓名:星见 | 外貌:银发蓝瞳 | 性格:冷静,寡言 | 出身:废土流浪者 | 定位:侦察 | 属性:战力:2/技巧:3/智慧:3/社交:1/谨慎:2/运气:1
</Character>
```

#### 3.1.2 CMD:MOD — 修改角色

```
<Character>
CMD:MOD | 角色名 | 字段名: 新值 | 字段名: 新值 | ...
</Character>
```

示例：

```
<Character>
CMD:MOD | 星见 | 状态: 派遣中 | 当前任务: run_001 | 属性:战力:3/技巧:2/智慧:3/社交:2/谨慎:2/运气:1
</Character>
```

> 支持任意键值对修改，包括自定义字段。属性修改格式为 `属性:战力:3/技巧:2/...`。

#### 3.1.3 CMD:DEL — 删除角色

```
<Character>
CMD:DEL | 角色名
</Character>
```

> 从 `role_db_map` 和 `roles` 中同时移除。

#### 3.1.4 CMD:EQUIP — 装备技能

```
<Character>
CMD:EQUIP | 角色名 | 技能名
</Character>
```

> 将指定技能加入角色的 `已装备技能` 列表。

#### 3.1.5 CMD:UNEQUIP — 卸下技能

```
<Character>
CMD:UNEQUIP | 角色名 | 技能名
</Character>
```

> 从角色的 `已装备技能` 列表中移除指定技能。

### 3.2 技能相关 CMD

#### 3.2.1 CMD:ADD_SKILL — 添加技能标签

```
<Skill>
CMD:ADD | 名称 | emoji | 描述 | mod:域.键
</Skill>
```


| 字段      | 说明             |
| ------- | -------------- |
| 名称      | 技能名称           |
| emoji   | 展示用 emoji      |
| 描述      | 效果描述文案         |
| mod:域.键 | 可选，技能可计算效果     |


> `mod:` 格式为 `域.键`，如 `派遣.trap负面率降低`、`工坊.通用产量加成`。数值由系统根据白名单范围自动生成（详见 `docs/技能mod白名单.md`），商城生成时可不附带具体数值。

#### 3.2.2 CMD:DEL_SKILL — 删除技能

```
<Skill>
CMD:DEL_SKILL | 技能名
</Skill>
```

### 3.3 正则表达式定义

```typescript
// 角色块匹配
const regexCharBlock = /<Character>\s*([\s\S]*?)\s*<\/Character>/gi;

// 角色 CMD 匹配（支持任意数量键值对）
// CMD:ADD 部分：提取 "CMD:ADD | 键1:值1 | 键2:值2 | ..." 格式
const regexCharAdd = /CMD:ADD\s*[|｜]\s*([\s\S]*?)(?=\s*CMD:|$)/gi;
const regexCharMod = /CMD:MOD\s*[|｜]\s*([^\|｜]+?)\s*[|｜]\s*([\s\S]*?)(?=\s*CMD:|$)/gi;
const regexCharDel = /CMD:DEL\s*[|｜]\s*([^\|｜]+?)(?=\s*[|｜]?\s*CMD:|$)/gi;
const regexCharEquip = /CMD:EQUIP\s*[|｜]\s*([^\|｜]+?)\s*[|｜]\s*([^\|｜]+?)(?=\s*[|｜]?\s*CMD:|$)/gi;
const regexCharUnequip = /CMD:UNEQUIP\s*[|｜]\s*([^\|｜]+?)\s*[|｜]\s*([^\|｜]+?)(?=\s*[|｜]?\s*CMD:|$)/gi;

// 技能块匹配
const regexSkillBlock = /<Skill>\s*([\s\S]*?)\s*<\/Skill>/gi;

// 技能 CMD 匹配
const regexSkillAdd = /CMD:ADD\s*[|｜]\s*([^\|｜]+?)\s*[|｜]\s*([^\|｜]+?)\s*[|｜]\s*([^\|｜]+?)(?:\s*[|｜]\s*(.+))?/gi;
const regexSkillDel = /CMD:DEL_SKILL\s*[|｜]\s*([^\|｜]+?)(?=\s*[|｜]?\s*CMD:|$)/gi;

// mod: 识别正则
const regexMod = /mod:\s*([^，,\s]+)\.([^，,\s]+)/;

/**
 * 解析键值对字符串（支持任意数量）
 * 输入: "姓名:星见 | 外貌:银发蓝瞳 | 年龄:28岁"
 * 输出: { "姓名": "星见", "外貌": "银发蓝瞳", "年龄": "28岁" }
 */
function parseKeyValuePairs(cmdPart: string): Record<string, string> {
  const fields: Record<string, string> = {};
  const parts = cmdPart.split(/[|｜]/);
  for (const part of parts) {
    const colonMatch = part.match(/^(.+?)[:：]\s*([\s\S]*)$/);
    if (colonMatch) {
      const key = colonMatch[1].trim();
      const value = colonMatch[2].trim();
      fields[key] = value;
    }
  }
  return fields;
}
```

> **注意**：`regexCharAdd` 现在使用贪婪匹配捕获整个 `CMD:ADD | 键:值 | 键:值 | ...` 部分，然后通过 `parseKeyValuePairs()` 按 `|` 分割处理，这样可以支持任意数量的键值对（包括自定义字段）。

#### 4.2.4 解析器设计

解析器负责从第二 API 返回的 `<Character>CMD:ADD|...</Character>` 提取内容，转换为角色对象供玩家预览确认。

```typescript
import { 角色Schema, type 角色 } from './types/role';

/**
 * 从第二 API 输出中解析 <Character>CMD:ADD|...</Character> 块
 * 返回 { cmdString, fields } 或 null
 */
export function parseCharacterCMD(raw: string): { cmdString: string; fields: Record<string, string> } | null {
  // 匹配 <Character>...</Character> 块
  const match = raw.match(/<Character>([\s\S]*?)<\/Character>/i);
  if (!match) return null;

  const content = match[1].trim();

  // 提取 CMD:ADD 部分
  const cmdMatch = content.match(/CMD:ADD\s*[|｜]\s*([\s\S]*?)(?=\s*CMD:|$)/i);
  if (!cmdMatch) return null;

  const cmdPart = cmdMatch[1].trim();
  const fields: Record<string, string> = {};

  // 按 | 分割，解析键值对
  const parts = cmdPart.split(/[|｜]/);
  for (const part of parts) {
    const colonMatch = part.match(/^(.+?)[:：]\s*([\s\S]*)$/);
    if (colonMatch) {
      const key = colonMatch[1].trim();
      const value = colonMatch[2].trim();
      fields[key] = value;
    }
  }

  return {
    cmdString: `<Character>\nCMD:ADD | ${cmdPart}\n</Character>`,
    fields,
  };
}

/**
 * 将解析后的字段转换为角色对象（用于预览）
 * 支持预定义字段 + 自定义字段
 */
export function fieldsToRole(fields: Record<string, string>): 角色 | null {
  // 解析属性
  const 属性: Record<string, number> = { 战力: 0, 技巧: 0, 智慧: 0, 社交: 0, 谨慎: 0, 运气: 0 };
  if (fields['属性']) {
    const attrParts = fields['属性'].split(/[/]/);
    for (const part of attrParts) {
      const [key, val] = part.split(':');
      if (key && val !== undefined) {
        const numVal = parseInt(val, 10);
        if (!isNaN(numVal)) 属性[key] = Math.min(5, Math.max(0, numVal));
      }
    }
  }

  // 预定义字段列表（用于过滤）
  const 预定义字段 = new Set([
    'id', '姓名', '外貌', '性格', '出身', '定位', '说话风格',
    '喜好', '特长', '职业', '背景故事', '属性', '已装备技能',
    '状态', '当前任务', '记录'
  ]);

  // 构建角色对象，预定义字段显式赋值，其余作为自定义字段
  const rawRole: Record<string, any> = {
    id: '',
    姓名: fields['姓名'] || '未知',
    外貌: fields['外貌'],
    性格: fields['性格'],
    出身: fields['出身'],
    定位: fields['定位'],
    说话风格: fields['说话风格'],
    喜好: fields['喜好'],
    特长: fields['特长'],
    职业: fields['职业'],
    背景故事: fields['背景故事'],
    属性,
    已装备技能: [],
    状态: '空闲',
    当前任务: null,
    记录: [],
  };

  // 添加自定义字段（不在预定义列表中的字段）
  for (const [key, value] of Object.entries(fields)) {
    if (!预定义字段.has(key)) {
      rawRole[key] = value;
    }
  }

  try {
    return 角色Schema.parse(rawRole);
  } catch (e) {
    console.error('[roleProfile] 预览转换失败', e);
    return null;
  }
}
```

```typescript
  // 2. 解析为预览数据
  const parsed = parseCharacterCMD(raw);
  if (!parsed) {
    console.error('[roleProfile] 解析失败，原始输出：', raw);
    return { confirmed: false };
  }

  // 3. 转换为角色对象用于预览
  const previewRole = fieldsToRole(parsed.fields);
  if (!previewRole) {
    return { confirmed: false };
  }

  // 4. 展示预览界面，让玩家确认
  const 用户确认 = await showRolePreview(parsed.cmdString, previewRole);
  if (!用户确认) {
    return { confirmed: false };
  }

  // 5. 插入聊天末尾
  const messages = getChatMessages('all');
  const lastMsg = messages[messages.length - 1];
  const newContent = (lastMsg?.content || '') + '\n\n' + parsed.cmdString;
  messages[messages.length - 1] = { ...lastMsg, content: newContent };
  setChatMessages(messages);

  // 6. 返回预览角色（扫描器会在下一轮写入变量）
  return { confirmed: true, role: previewRole };
}
```

### 4.3.4 解析器设计

```typescript
import { 技能效果白名单, 随机分配效果值 } from './utils/skillEffectWhitelist';

/**
 * 解析技能标签行
 * 输入: "潜行专精|🔥|降低被发现概率|80|mod:派遣.隐蔽加成"
 * 返回: SkillShopItem
 */
export function parseSkillShopLine(line: string): SkillShopItem | null {
  const parts = line.split('|').map(s => s.trim());
  if (parts.length < 4) return null;

  const [名称, emoji, 描述, 价格Str, ...modParts] = parts;
  const 价格 = parseInt(价格Str, 10);
  if (!名称 || isNaN(价格)) return null;

  // 解析 mod: 并随机分配效果值
  const 效果: SkillShopItem['效果'] = [];
  const modStr = modParts.join('|');
  const modMatches = modStr.matchAll(/mod:\s*([^，,\s]+)\.([^，,\s]+)/g);
  for (const match of modMatches) {
    const 域 = match[1];
    const 键 = match[2];
    const 值 = 随机分配效果值(域, 键);
    if (值 !== null) {
      效果.push({ 域, 键, 值 });
    }
  }

  return {
    id: `skill_${Date.now()}_${Math.random().toString(36).slice(2, 7)}`,
    名称,
    emoji,
    描述,
    价格,
    效果,
  };
}
```

## 5. 聊天扫描引擎

### 5.1 扫描模式


| 模式                | 说明             | 触发时机        |
| ----------------- | -------------- | ----------- |
| 全量扫描（full）        | 从第一条消息开始扫描全部聊天 | 初始化、删楼后     |
| 增量扫描（incremental） | 从检查点之后开始扫描新消息  | 正常对话中（节流防抖） |


### 5.2 增量扫描检查点机制

检查点保存扫描进度，确保每次只处理新消息：

```typescript
interface 角色检查点 {
  message_id: number;  // 已扫描到的最后一条消息 ID
  max_id: number;      // 检查点时的最大角色序号
  db_map: Record<string, 角色>;  // 检查点时的角色字典快照
}
```

**保存检查点时机：**

- 每隔 N 条消息自动保存（`checkpointInterval`，建议 25）
- 用户手动触发（如点击"重建索引"按钮）
- 扫描结束时保存

**增量扫描流程：**

```typescript
function performScan(mode: 'full' | 'incremental') {
  const allMessages = getChatMessages('0-{{lastMessageId}}');
  let scanFromIndex = 0;

  // 读取检查点
  const checkpoint = getVariables({ type: 'chat' }).role_checkpoint;

  if (mode === 'incremental' && checkpoint?.message_id) {
    // 从检查点恢复状态
    const cpMsgId = checkpoint.message_id;
    scanFromIndex = allMessages.findIndex(m => m.message_id > cpMsgId);
    if (scanFromIndex === -1) return; // 没有新消息

    // 恢复已处理的数据
    Object.assign(roleDbMap, checkpoint.db_map);
    roleMaxId = checkpoint.max_id;
  }

  // 从 scanFromIndex 开始扫描新消息
  for (const msg of allMessages.slice(scanFromIndex)) {
    scanMessage(msg);
  }

  // 保存检查点
  if (shouldSaveCheckpoint()) {
    saveCheckpoint();
  }
}
```

## 6. Prompt 注入（按需发送角色数据给 AI）

### 6.1 设计思路

角色数据**不自动注入主对话**，而是**按需发送给第二 API**，实现按场景灵活传递：


| 场景         | 发送的角色数据       | 说明         |
| ---------- | ------------- | ---------- |
| 废土行路·事件生成  | 派遣角色列表 + 技能效果 | 只发送正在派遣的角色 |
| 末世通讯·与角色聊天 | 指定角色的完整档案     | 只发送聊天对象的角色 |
| 角色管理面板     | 所有角色列表        | 展示所有角色供管理  |


**核心原则：**

- 每个角色数据单独储存，可按需组合
- 第二 API 调用时动态组装需要的数据
- 数据格式化后便于 AI 阅读

### 6.2 数据格式化

```typescript
function formatRoleForAI(role: 角色): string {

  lines.push(`【角色：${role.姓名}】`);

  if (role.出身) lines.push(`- 出身：${role.出身}`);
  if (role.定位) lines.push(`- 定位：${role.定位}`);
  if (role.职业) lines.push(`- 职业：${role.职业}`);
  if (role.说话风格) lines.push(`- 说话风格：${role.说话风格}`);
  if (role.喜好) lines.push(`- 喜好：${role.喜好}`);
  if (role.特长) lines.push(`- 特长：${role.特长}`);
  if (role.背景故事) lines.push(`- 背景：${role.背景故事}`);

  // 2. 自定义字段（通过 catchall 存储的任意字段）
  const customFields = Object.entries(role).filter(
    ([key]) => !预定义字段.has(key) && !key.startsWith('_')
  );
  for (const [key, value] of customFields) {
    if (value !== undefined && value !== null && value !== '') {
      // 根据值类型格式化
      const valueStr = typeof value === 'object'
        ? JSON.stringify(value)
        : String(value);
      lines.push(`- ${key}：${valueStr}`);
    }
  }

  // 3. 属性（固定格式）
  const attrs = Object.entries(role.属性)
    .map(([k, v]) => `${k}:${v}`)
    .join(' / ');
  lines.push(`- 属性：${attrs}`);

  // 4. 装备技能
  if (role.已装备技能.length > 0) {
    const skills = role.已装备技能.map(s => {
      const skill = skillDbMap[s];
      return skill ? `${skill.名称}` : s;
    }).join('、');
    lines.push(`- 装备技能：${skills}`);
  }

  // 5. 当前状态
  lines.push(`- 状态：${role.状态}`);

  return lines.join('\n');
}

/**
 * 格式化角色列表为 AI 可读的文本
 */
function formatRoleListForAI(roles: 角色[], 标题: string): string {
  if (roles.length === 0) return '';

  const header = `【${标题}】\n（共 ${roles.length} 名角色）`;
  const body = roles.map(r => formatRoleForAI(r)).join('\n\n');
  return `${header}\n${body}`;
}
```

### 6.4 第二 API 调用封装

```typescript
/**
 * 第二 API 调用封装
 * 支持传入需要注入的角色数据
 */
export async function callSecondApiWithRoles(
  task: string,
  需要的角色: 角色[],
  options: {
    extraSkills?: string[],  // 额外技能效果描述
    额外上下文?: string,
  } = {}
): Promise<string> {
  const rolePrompt = formatRoleListForAI(需要的角色, '角色档案');

  const systemParts: string[] = [
    rolePrompt,
  ];

  if (options.extraSkills?.length) {
    systemParts.push(`【技能效果】\n${options.extraSkills.join('\n')}`);
  }

  if (options.额外上下文) {
    systemParts.push(`【额外信息】\n${options.额外上下文}`);
  }

  const result = await callSecondApi(task, {
    ordered_prompts: [
      'world_info',
      'char_persona',
      'chat_history',
      { role: 'system', content: systemParts.join('\n\n') },
    ]
  });

  return result as string;
}
```
