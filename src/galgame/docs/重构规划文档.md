## 一、用户确认的架构决策（v2）

> ⚠️ **重要澄清（2026-05-31 修正）**：

1. **工坊不是完全删掉！** 订单制还是保留，角色在工坊持续生产金币，有计时器和收益。本质上与订单的思路类似，只是 UI 变化了。**工坊保留！**
2. **DispatchModule 不需要角色管理！** 角色管理是单独的模块。DispatchModule 只负责废土行路（格子地图），在派遣**前**会有一个选角色、输入地点和相关要求的环境（但角色管理本身不是 DispatchModule 的一部分）。

4. **背包包含角色装备**：参考 `酒馆助手脚本-物品栏.json`，InventoryModule 需要扩展为道具 + 角色装备。

角色管理是**单独的模块**，不在 DispatchModule 里：

| ------- | ------------------ |

### 2.6 DispatchModule.vue（废土行路）

DispatchModule 只负责废土行路（格子地图），**不包含角色 CRUD 管理**。角色选择 phase（用于选择派遣角色）是 DispatchModule 的一部分，这个没问题。

DispatchModule 的 "selectCharacter" phase 是**选角色去派遣**，这是废土行路的必要流程，不是角色管理 CRUD。

真正的**角色管理**（生成角色、查看档案、装备技能、编辑/删除角色）是单独的。

```
DispatchModule.vue（废土行路入口）
│
├── Phase 1: selectDestination
│     └─ 选择目的地
│
├── Phase 2: selectCharacter  ← 选角色去派遣（这是 Dispatch 的一部分，不是角色管理 CRUD！）
│     └─ 从现有角色中选择一个派遣角色
│
├── Phase 3: confirm
│     └─ 路线选择 + 地图预览
│
├── Phase 4: inProgress  ← 嵌入 BoardGameModule.vue 的核心 UI
│     ├─ 复用格子地图（完全保留 BoardGameModule 的地图渲染！）
│     ├─ 复用骰子（WastelandDice.vue）
│     ├─ 复用事件卡翻转动画
│     └─ 复用 boardGameStore 状态机
│
└── Phase 5: settlement
```
