本文档用于细化 `src/galgame/boardgame` 中的「废土行路」玩法与角色系统的深度整合，是《玩法-角色与派遣规划.md》的下游实现文档。

**前置文档**：《玩法-角色与派遣规划.md》、《角色系统详细设计.md》

> 备注：本文档聚焦于派遣玩法的完整流程设计，包括角色选择、属性影响、技能加成、事件抽取、结算系统等核心机制的实现细节。

### 2.2 变量存储结构

#### 2.2.1 派遣活动状态（dispatchActive）

> **生命周期**：仅在派遣进行中保存，派遣结束后清空。

```typescript
// 位于聊天变量 dispatchActive
interface DispatchActive {
  // 基本信息
  runIndex: number;           // 派遣序号（从 1 开始，每次派遣 +1）
  roleId: string;             // 角色 ID
  roleName: string;           // 角色姓名（冗余便于展示）
  location: string;           // 地点名称
  extraContext: string;       // 附加剧情/要求（玩家输入）
  route: 'short' | 'medium' | 'long';  // 路线长度

  // 地图状态（用于恢复）
  seed: number;               // 地图种子

  // 玩家状态（完整保存 HP/Sanity）
  stats: {
    hp: number;
    maxHp: number;
    sanity: number;
    maxSanity: number;
  };

  // 位置与步数
  currentNodeId: string;      // 当前位置
  totalSteps: number;        // 总步数

  // 事件池快照（用于恢复）
  eventPoolSnapshot: GameEvent[];

  // 行路日志（完整保存，每次事件结算追加）
  eventLog: DispatchEventLog[];

  // 战斗收益（累计）
  battleReward: BattleReward;
}

interface DispatchEventLog {
  eventTitle: string;    // 事件标题（如"锈蚀的地雷：缓慢后退"）
  message: string;        // 结算描述（如"地雷没有爆炸，但脚踝被锈铁割伤了。"）
  hpChange: number;      // HP 变化量（如 -5、+8）
  sanityChange: number;   // Sanity 变化量（如 -5、+12）
}

interface BattleReward {
  lootCount: number;      // 战斗掉落的纪念品数量（由怪物 lootChance 决定）
  goldBonus: number;      // 战斗金币加成
}
```

> **设计说明**：
>
> - `eventTitle` + `message` 已包含事件完整信息，用于 AI 生成连贯的旅途故事
> - `hpChange`/`sanityChange` 让 AI 可以描述"受了重伤"或"精神受创"
> - 格子类型（trap/fortune/encounter）只在事件抽取阶段起作用，故事生成时不需要

#### 2.2.2 派遣历史记录（dispatchRuns）

> **生命周期**：持久保存，派遣结束后追加，不删除。

```typescript
// 位于聊天变量 dispatchRuns[]
interface DispatchRun {
  // 基本信息
  runIndex: number;           // 派遣序号
  roleName: string;           // 角色姓名
  location: string;           // 地点
  route: 'short' | 'medium' | 'long';  // 路线长度

  // 结算结果
  result: 'success' | 'forced' | 'cancelled';  // 成功/强制/取消

  // 收益（仅记录数量，详细内容由 AI 生成）
  rewards: {
    gold: number;              // 金币数量
    souvenirCount: number;     // 纪念品数量（用于拼装提示词）
  };

  // 旅途故事（AI 生成，完整保存）
  story: string;
}
```

**设计说明**：

- `DispatchActive` 在派遣结束后清空（设为 `null`）
- `souvenirCount` 仅用于告诉 AI 生成多少个纪念品，纪念品名称由 AI 自行发挥

```

## 3. 角色选择与恢复机制

### 3.1 入口流程

```typescript
// dispatchEngine.ts

/**
 * 获取下一个派遣序号
 */
function getNextRunIndex(): number {
  const runs = getDispatchRuns();
  if (runs.length === 0) return 1;
  return Math.max(...runs.map(r => r.runIndex)) + 1;
}

/**
 * 进入派遣前的角色选择
 * 返回：是否成功进入派遣
 */
export async function enterDispatch(): Promise<{
  success: boolean;
  roleId?: string;
  recovered?: boolean;
}> {
  // 1. 获取所有角色
  const roles = getRoles();

  // 2. 检查是否有可派遣角色
  const availableRoles = roles.filter(r =>
    r.状态 === '空闲' || r.状态 === '休息中'
  );

  if (availableRoles.length === 0) {
    toastr.warning('没有可派遣的角色');
    return { success: false };
  }

  // 3. 检查是否存在未完成的派遣
  const dispatchActive = getDispatchActive();
  if (dispatchActive) {
    // 恢复派遣
    await recoverDispatch(dispatchActive);
    return { success: true, roleId: dispatchActive.roleId, recovered: true };
  }

  // 4. 弹出角色选择面板（包含地点和附加剧情输入）
  const result = await showRoleSelectPanel(availableRoles);
  if (!result || !result.roleId) {
    return { success: false };
  }

  const { roleId, location, extraContext, route } = result;

  // 5. 创建新的派遣活动状态
  const runIndex = getNextRunIndex();
  const role = getRole(roleId);

  const newActive: DispatchActive = {
    runIndex,
    roleId,
    roleName: role?.姓名 ?? '未知',
    location,
    extraContext,  // 保存附加剧情/要求
    route,         // 保存路线长度
    seed: Math.floor(Math.random() * 999999),
    stats: {
      hp: 80,
      maxHp: 100,
      sanity: 70,
      maxSanity: 100,
      luck: 5,
    },
    currentNodeId: '',
    totalSteps: 0,
    eventPoolSnapshot: [],
    eventLog: [],
    battleReward: {
      lootCount: 0,
      goldBonus: 0,
    },
  };

  // 6. 保存活动状态并初始化 boardgame
  saveDispatchActive(newActive);
  initBoardGameFromDispatch(newActive);

  // 7. 更新角色状态
  updateRoleStatus(roleId, '派遣中');

  return { success: true, roleId, recovered: false };
}

/**
 * 初始化 boardgame（基于派遣活动状态）
 */
function initBoardGameFromDispatch(active: DispatchActive): void {
  const boardGameStore = useBoardGameStore();

  // 生成地图（根据路线长度）
  boardGameStore.seed = active.seed;
  boardGameStore.mapConfig = generateMap(active.seed, active.route);

  // 初始化玩家状态
  boardGameStore.stats = { ...active.stats };

  // 重置位置
  boardGameStore.currentNodeId = boardGameStore.mapConfig.startNodeId;
  boardGameStore.totalSteps = 0;

  // 初始化事件池
  boardGameStore.eventPool = generateEventPool();

  // 初始化战斗收益
  boardGameStore.battleReward = { lootCount: 0, goldBonus: 0 };
}

/**
 * 恢复未完成的派遣
 */
async function recoverDispatch(active: DispatchActive): Promise<void> {
  const boardGameStore = useBoardGameStore();

  // 恢复地图
  boardGameStore.seed = active.seed;
  boardGameStore.mapConfig = generateMap(active.seed, active.route);

  // 恢复玩家状态
  boardGameStore.stats = { ...active.stats };

  // 恢复位置（需要重新计算节点 ID）
  const nodes = boardGameStore.mapConfig.nodes;
  const targetNode = nodes.find(n => n.id === active.currentNodeId);
  if (targetNode) {
    boardGameStore.currentNodeId = active.currentNodeId;
  } else {
    boardGameStore.currentNodeId = boardGameStore.mapConfig.startNodeId;
  }

  // 恢复事件池
  boardGameStore.eventPool = [...active.eventPoolSnapshot];

  // 恢复步数
  boardGameStore.totalSteps = active.totalSteps;

  toastr.info(`已恢复 ${active.roleName} 的派遣（${active.location}）`);
}
```

## 4. 格子类型与事件系统

### 4.0 格子类型定义

```typescript
// types.ts
export type NodeType = 'start' | 'empty' | 'encounter' | 'trap' | 'fortune' | 'battle' | 'end';

/**
 * 格子类型说明：
 * - start：起点，不触发事件
 * - empty：空地，不触发事件
 * - encounter：遭遇格，所有倾向等概率
 * - trap：陷阱格，偏负面 (negative 60%, neutral 25%, positive 15%)
 * - fortune：意外之喜，偏正面 (positive 60%, neutral 25%, negative 15%)
 * - battle：战斗格，使用角色属性计算战斗结果（新增）
 * - end：终点，触发结算
 */
```

### 4.1 战斗格子（battle）设计

> 战斗格子是新增的格子类型，进入时触发战斗事件。
> 战斗结果：胜利/失败/险胜（运气触发）/逃走（运气触发）
> 战利品作为纪念品计入收益。

```typescript
// battleConfig.ts

/**
 * 伤害类型
 */
export type DamageType = 'physical' | 'mental' | 'mixed' | 'piercing';

/**
 * 怪物模板
 */
export interface MonsterTemplate {
  id: string;
  name: string;                    // 怪物名称
  description: string;              // 描述（用于 AI 生成战斗叙事）

  // 难度与克制
  difficulty: number;               // 难度等级（1-5）
  weakAttribute: keyof RoleAttributes;  // 克制属性（击败它时加成）

  // 伤害设计
  damageType: DamageType;           // 伤害类型
  baseDamage: number;              // 基础伤害
  damageRange: number;             // 伤害浮动范围（如 ±10）

  // 精神攻击
  mentalDamage: number;            // 精神伤害
  mentalChance: number;            // 精神攻击触发概率（0-1）

  lootChance: number;             // 掉落概率（胜利时）

 * 战斗结果类型
 */
export type BattleOutcome = 'victory' | 'defeat' | 'narrow_escape' | 'escape';

): MonsterTemplate {
  // 派遣进度越高，遇到的怪物难度越高
  // 进度 0-0.3: 难度 1-2
  // 进度 0.3-0.6: 难度 2-3
  // 进度 0.6-0.8: 难度 3-4
  // 进度 0.8-1.0: 难度 4-5

  const minDiff = Math.floor(dispatchProgress * 4) + 1;
  const maxDiff = Math.min(5, minDiff + 1);
  const available = monsterPool.filter(m => m.difficulty >= minDiff && m.difficulty <= maxDiff);

  if (available.length === 0) {
    return monsterPool[Math.floor(Math.random() * 2)]!;
  }

  return available[Math.floor(Math.random() * available.length)]!;
}

### 4.1.2 战斗胜率计算

```typescript
// battleConfig.ts

/**
 * 计算战斗胜率
 *
 * 公式：baseWinRate + powerBonus + wisdomBonus + socialBonus - difficultyPenalty
 *
 * - baseWinRate：基础胜率 50%
 * - powerBonus：战力每点 +5%（对抗物理/穿刺伤害怪物）
 * - wisdomBonus：智慧每点 +3%（对抗精神/混合伤害怪物）
 * - socialBonus：社交每点 +4%（对抗帮派类怪物）
 * - luckBonus：运气每点 +2%（所有战斗）
 * - weakAttributeBonus：针对克制属性 +15%
 * - difficultyPenalty：难度每级 -8%
 */
export function calculateWinRate(
  attributes: RoleAttributes,
  monster: MonsterTemplate,
): number {
  const baseWinRate = 0.5;

  // 属性加成
  let powerBonus = (attributes.战力 - 3) * 0.05;
  let wisdomBonus = (attributes.智慧 - 3) * 0.03;
  let socialBonus = (attributes.社交 - 3) * 0.04;
  let luckBonus = (attributes.运气 - 3) * 0.02;

  // 克制属性加成
  let weakAttributeBonus = 0;
  if (monster.weakAttribute === '战力' && attributes.战力 >= 5) weakAttributeBonus = 0.15;
  if (monster.weakAttribute === '智慧' && attributes.智慧 >= 5) weakAttributeBonus = 0.15;
  if (monster.weakAttribute === '社交' && attributes.社交 >= 5) weakAttributeBonus = 0.15;
  if (monster.weakAttribute === '运气' && attributes.运气 >= 5) weakAttributeBonus = 0.15;

  // 伤害类型适应性
  let typeBonus = 0;
  if (monster.damageType === 'physical' || monster.damageType === 'piercing') {
    typeBonus = powerBonus;
  } else if (monster.damageType === 'mental') {
    typeBonus = wisdomBonus;
  } else {
    // mixed 类型，取两者平均
    typeBonus = (powerBonus + wisdomBonus) / 2;
  }

  // 难度惩罚
  const difficultyPenalty = (monster.difficulty - 1) * 0.08;

  const winRate = baseWinRate + typeBonus + socialBonus + luckBonus + weakAttributeBonus - difficultyPenalty;

  // 限制在 10%~95% 之间
  return Math.round(Math.max(0.1, Math.min(0.95, winRate)) * 100) / 100;
}
```

### 4.1.3 战斗流程设计

> 战斗分为两个阶段：
>
> 1. **初始战斗**：投骰子决定初始结果
> 2. **选择阶段**：若失败，玩家选择逃走或再战

```typescript
// battleConfig.ts

/**
 * 初始战斗结果（第一阶段）
 */
export type InitialBattleResult = 'victory' | 'defeat';

/**
 * 战斗选择（第二阶段）
 */
export type BattleChoice = 'escape' | 'retry';

/**
 * 再战消耗配置
 */
export const RETRY_COST = 50;  // 再战消耗 50 金币

/**
 * 计算再战后的胜率（骰子点数 + 运气矫正）
 *
 * 公式：(roll * 100) + luck * 5
 *
 * - roll：0-1 的随机数
 * - luck：运气属性
 * - 结果限制在 0-100
 */
export function calculateRetryWinRate(
  luck: number,
  rng: () => number = Math.random,
): number {
  const roll = rng() * 100;  // 转换为 0-100
  const luckBonus = luck * 5;
  return Math.max(0, Math.min(100, roll + luckBonus));
}

/**
 * 执行初始战斗（第一阶段）
 */
export function executeInitialBattle(
  attributes: RoleAttributes,
  monster: MonsterTemplate,
  rng: () => number = Math.random,
): { initialResult: InitialBattleResult; winRate: number } {
  const winRate = calculateWinRate(attributes, monster);
  const roll = rng() * 100;  // 转换为 0-100
  const victory = roll < winRate * 100;

  return {
    initialResult: victory ? 'victory' : 'defeat',
    winRate,
  };
}

/**
 * 执行再战（第二阶段）
 */
export function executeRetryBattle(
  luck: number,
  rng: () => number = Math.random,
): BattleOutcome {
  const winRate = calculateRetryWinRate(luck, rng);

  if (winRate >= 70) {
    // 70 以上险胜
    return 'narrow_escape';
  } else {
    // 70 以下战败
    return 'defeat';
  }
}

/**
 * 战斗结果（完整）
 */
export interface BattleResult {
  initialResult: InitialBattleResult | null;  // 第一阶段结果（胜利时直接结束）
  finalOutcome: BattleOutcome;               // 最终结果
  winRate: number;                          // 初始胜率
  retryWinRate: number | null;              // 再战胜率（仅显示）
  hpChange: number;                         // HP 变化
  sanityChange: number;                      // Sanity 变化
  lootDropped: boolean;                     // 是否掉落纪念品
  retryCost: number;                        // 再战消耗金币
}

### 4.1.4 执行完整战斗流程

```typescript
// battleConfig.ts

/**
 * 完整战斗执行
 *
 * 战斗流程：
 * 1. 计算基础胜率
 * 2. 投骰子决定初始结果
 * 3. 若胜利 → 结算
 * 4. 若失败 → 玩家选择：
 *    - 逃走：无收益、无伤害
 *    - 再战：消耗金币，再次投骰子
 * 5. 若再战失败 → 战败（有伤害）
 * 6. 若再战成功 → 险胜（基础奖励）
 * 7. 计算伤害
 * 8. 判断战利品掉落
 */
export function executeBattle(
  attributes: RoleAttributes,
  monster: MonsterTemplate,
  playerChoice: BattleChoice | null,  // null 表示需要玩家选择
  rng: () => number = Math.random,
): BattleResult {
  const winRate = calculateWinRate(attributes, monster);
  const retryWinRate = calculateRetryWinRate(attributes.运气, rng);

  // ── 阶段一：初始战斗 ────────────────────────────────────────────
  const { initialResult } = executeInitialBattle(attributes, monster, rng);

  if (initialResult === 'victory') {
    // ── 胜利，直接结算 ───────────────────────────────────────────
    const hpChange = -Math.round(monster.baseDamage * (0.1 + rng() * 0.2));
    const sanityChange = rng() < monster.mentalChance
      ? -Math.round(monster.mentalDamage * (0.5 + rng() * 0.5))
      : 0;
    const lootDropped = rng() < monster.lootChance;

    return {
      initialResult: 'victory',
      finalOutcome: 'victory',
      winRate,
      retryWinRate,
      hpChange,
      sanityChange,
      lootDropped,
      retryCost: 0,
    };
  }

  // ── 阶段二：玩家选择 ────────────────────────────────────────────
  if (playerChoice === null) {
    // 需要玩家选择，暂不结算
    return {
      initialResult: 'defeat',
      finalOutcome: 'defeat',  // 临时
      winRate,
      retryWinRate,
      hpChange: 0,
      sanityChange: 0,
      lootDropped: false,
      retryCost: RETRY_COST,
    };
  }

  if (playerChoice === 'escape') {
    // ── 逃走：无收益、无伤害 ───────────────────────────────────────
    return {
      initialResult: 'defeat',
      finalOutcome: 'escape',
      winRate,
      retryWinRate,
      hpChange: 0,
      sanityChange: 0,
      lootDropped: false,
      retryCost: 0,
    };
  }

  // ── 再战：消耗金币，再次投骰子 ─────────────────────────────────
  const retryResult = executeRetryBattle(attributes.运气, rng);

  if (retryResult === 'narrow_escape') {
    // ── 险胜：基础奖励，无战利品 ─────────────────────────────────
    const hpChange = -Math.round(monster.baseDamage * (0.4 + rng() * 0.3));
    const sanityChange = -Math.round(monster.mentalDamage * 0.6);

    return {
      initialResult: 'defeat',
      finalOutcome: 'narrow_escape',
      winRate,
      retryWinRate,
      hpChange,
      sanityChange,
      lootDropped: false,
      retryCost: RETRY_COST,
    };
  }

  // ── 战败：无奖励，有伤害 ───────────────────────────────────────
  const hpChange = -Math.round(monster.baseDamage + (rng() - 0.5) * monster.damageRange);
  const sanityChange = -Math.round(monster.mentalDamage * (0.8 + rng() * 0.4));

  return {
    initialResult: 'defeat',
    finalOutcome: 'defeat',
    winRate,
    retryWinRate,
    hpChange,
    sanityChange,
    lootDropped: false,
    retryCost: RETRY_COST,
  };
}
```

### 4.1.5 战斗对收益的影响

> 战斗结果影响结算收益：
>
> - victory（胜利）：完整奖励 + 战利品
> - narrow_escape（险胜）：少量奖励，无战利品
> - escape（逃走）：无收益、无伤害
> - defeat（战败）：无奖励、有伤害

```typescript
// battleConfig.ts

/**
 * 战斗结果对收益的影响
 */
export interface BattleRewardImpact {
  goldBonus: number;      // 金币加成
  lootBonus: number;     // 纪念品加成（胜利时由怪物 lootChance 决定）
  retryCost: number;      // 再战消耗金币
}

export function getBattleRewardImpact(
  result: BattleResult,
  rng: () => number = Math.random,
): BattleRewardImpact {
  const { finalOutcome, monster, retryCost } = result;

  switch (finalOutcome) {
    case 'victory':
      return {
        goldBonus: monster.difficulty * 50,  // 难度越高，金币越多
        lootBonus: rng() < monster.lootChance ? 1 : 0,  // 由怪物 lootChance 决定
        retryCost,
      };

    case 'narrow_escape':
      return {
        goldBonus: Math.round(monster.difficulty * 25),
        lootBonus: 0,
        retryCost,
      };

    case 'escape':
      return {
        goldBonus: 0,
        lootBonus: 0,
        retryCost: 0,
      };

    case 'defeat':
      return {
        goldBonus: 0,
        lootBonus: 0,
        retryCost,
      };
  }
}

```typescript
// dispatchEngine.ts

/**
 * 生成事件池（包含特殊效果）
 *
 * 1. 生成 35-50 张基础事件卡牌
 * 2. 随机选择 3-5 张卡牌附加传送效果
 * 3. 随机选择 2-3 张积极倾向卡牌附加纪念品增加效果
 */
export function generateEventPool(
  rng: () => number = Math.random,
): GameEventWithEffect[] {
  // 1. 生成基础事件池
  const poolSize = Math.floor(rng() * (EVENT_POOL_CONFIG.POOL_SIZE.max - EVENT_POOL_CONFIG.POOL_SIZE.min + 1))
    + EVENT_POOL_CONFIG.POOL_SIZE.min;

  const basePool: GameEventWithEffect[] = [];
  for (let i = 0; i < poolSize; i++) {
    basePool.push(generateRandomEvent(i, rng));
  }

  // 2. 随机选择 2-3 张卡牌附加传送效果
  const teleportCount = Math.floor(rng() * (EVENT_POOL_CONFIG.TELEPORT_COUNT.max - EVENT_POOL_CONFIG.TELEPORT_COUNT.min + 1))
    + EVENT_POOL_CONFIG.TELEPORT_COUNT.min;

  const teleportIndices = selectRandomIndices(poolSize, teleportCount, rng);
  for (const idx of teleportIndices) {
    basePool[idx].effect = {
      type: 'teleport',
      description: EFFECT_DESCRIPTIONS.teleport[Math.floor(rng() * EFFECT_DESCRIPTIONS.teleport.length)]!,
    };
  }

  // 3. 随机选择 1-2 张积极倾向卡牌附加纪念品增加效果
  const souvenirBoostCount = Math.floor(rng() * (EVENT_POOL_CONFIG.SOUVENIR_BOOST_COUNT.max - EVENT_POOL_CONFIG.SOUVENIR_BOOST_COUNT.min + 1))
    + EVENT_POOL_CONFIG.SOUVENIR_BOOST_COUNT.min;

  // 只从 positive 倾向的事件中选择
  const positiveIndices = basePool
    .map((e, i) => ({ event: e, index: i }))
    .filter(({ event }) => event.tendency === 'positive')
    .map(({ index }) => index);

  if (positiveIndices.length > 0) {
    const souvenirIndices = selectRandomIndices(positiveIndices.length, souvenirBoostCount, rng)
      .map(i => positiveIndices[i]);

    for (const idx of souvenirIndices) {
      // 不覆盖已有的传送效果
      if (!basePool[idx].effect) {
        basePool[idx].effect = {
          type: 'souvenir_boost',
          description: EFFECT_DESCRIPTIONS.souvenir_boost[Math.floor(rng() * EFFECT_DESCRIPTIONS.souvenir_boost.length)]!,
        };
      }
    }
  }

  return basePool;
}

/**
 * 随机选择不重复的索引
 */
function selectRandomIndices(
  maxIndex: number,
  count: number,
  rng: () => number,
): number[] {
  const indices = new Set<number>();
  const actualCount = Math.min(count, maxIndex);

  while (indices.size < actualCount) {
    indices.add(Math.floor(rng() * maxIndex));
  }

  return Array.from(indices);
}

// dispatchEngine.ts

/**
 * 角色属性对抽卡的修正
 *
 * 修正规则：
 * - 谨慎：降低 trap 格子的 negative 概率
 * - 运气：提高 fortune 格子的 positive 概率
 * - 智慧：使 encounter 格子结果趋向 neutral/positive
 */
export function calculateAttributeModifiers(
  nodeType: NodeType,
  attributes: RoleAttributes,
): TendencyWeights {
  const base = getBaseTendencyWeights(nodeType);
  const mod = { ...base };

  switch (nodeType) {
    case 'trap':
      // 谨慎每点降低 5% negative 概率
      mod.negative = Math.max(0.1, base.negative - (attributes.谨慎 - 3) * 0.05);
      mod.positive = Math.min(0.5, base.positive + (attributes.谨慎 - 3) * 0.03);
      break;

    case 'fortune':
      // 运气每点增加 5% positive 概率
      mod.positive = Math.min(0.8, base.positive + (attributes.运气 - 3) * 0.05);
      mod.negative = Math.max(0.05, base.negative - (attributes.运气 - 3) * 0.03);
      break;

    case 'encounter':
      // 智慧每点增加 5% neutral 概率，降低极端结果
      mod.neutral = Math.min(0.5, base.neutral + (attributes.智慧 - 3) * 0.05);
      mod.negative = Math.max(0.15, base.negative - (attributes.智慧 - 3) * 0.03);
      mod.positive = Math.max(0.15, base.positive - (attributes.智慧 - 3) * 0.03);
      break;
  }

  // 归一化
  const total = mod.negative + mod.neutral + mod.positive;
  mod.negative /= total;
  mod.neutral /= total;
  mod.positive /= total;

  return mod;
}

/**
 * 计算技能标签的抽卡层加成
 *
 * mod:派遣.trap负面率降低
 * mod:派遣.fortune正面率提高
 * mod:派遣.encounter趋向中性
 * mod:派遣.多抽一张卡
 * mod:派遣.重抽一次
 * mod:派遣.避开极端负面
 */
export function calculateSkillTendencyModifiers(
  skills: Skill[],
  nodeType: NodeType,
): {
  tendencyWeights: TendencyWeights;
  extraDraw: boolean;
  rerollChance: number;
  avoidExtreme: number;
} {
  const result = {
    tendencyWeights: getBaseTendencyWeights(nodeType),
    extraDraw: false,
    rerollChance: 0,
    avoidExtreme: 0,
  };

  for (const skill of skills) {
    for (const mod of skill.效果) {
      switch (mod.键) {
        case 'trap负面率降低':
          if (nodeType === 'trap') {
            result.tendencyWeights.negative = Math.max(0.1,
              result.tendencyWeights.negative - mod.值 / 100);
          }
          break;

        case 'fortune正面率提高':
          if (nodeType === 'fortune') {
            result.tendencyWeights.positive = Math.min(0.8,
              result.tendencyWeights.positive + mod.值 / 100);
          }
          break;

        case 'encounter趋向中性':
          if (nodeType === 'encounter') {
            result.tendencyWeights.neutral = Math.min(0.6,
              result.tendencyWeights.neutral + mod.值 / 100);
            result.tendencyWeights.negative = Math.max(0.1,
              result.tendencyWeights.negative - mod.值 / 200);
            result.tendencyWeights.positive = Math.max(0.1,
              result.tendencyWeights.positive - mod.值 / 200);
          }
          break;

        case '多抽一张':
          result.extraDraw = true;
          break;

        case '重抽概率':
          result.rerollChance = Math.max(result.rerollChance, mod.值 / 100);
          break;

        case '避开极端':
          result.avoidExtreme = Math.max(result.avoidExtreme, mod.值 / 100);
          break;
      }
    }
  }

  return result;
}

/**
 * 从事件池抽取事件（考虑角色属性和技能加成）
 */
export function drawEventWithModifiers(
  nodeType: NodeType,
  roleId: string,
): DrawResult {
  const boardGameStore = useBoardGameStore();

  // 1. 获取角色和技能
  const role = getRole(roleId);
  if (!role) {
    // 回退到普通抽取
    return { event: boardGameStore.drawEventFromPool(nodeType), wasRerolled: false, wasModified: false, appliedSkills: [] };
  }

  const skills = role.已装备技能.map(id => getSkill(id)).filter(Boolean);

  // 2. 计算属性修正
  const attrMod = calculateAttributeModifiers(nodeType, role.属性);

  // 3. 计算技能修正
  const skillMod = calculateSkillTendencyModifiers(skills, nodeType);

  // 4. 合并修正
  const finalWeights = mergeTendencyWeights(attrMod, skillMod.tendencyWeights);

  // 5. 从事件池中查找匹配的事件
  const pool = boardGameStore.eventPool;
  let candidates = pool.filter(e => e.nodeType === nodeType);

  if (candidates.length === 0) {
    candidates = pool;
  }

  // 6. 按倾向权重抽取
  let selected = weightedRandomDraw(candidates, finalWeights);

  // 7. 处理极端负面重抽
  if (selected && skillMod.avoidExtreme > 0) {
    const hpChange = selected.effect.hp ?? 0;
    const sanityChange = selected.effect.sanity ?? 0;
    if (hpChange <= -10 || sanityChange <= -15) {
      if (Math.random() < skillMod.avoidExtreme) {
        // 重抽
        const alternatives = candidates.filter(e =>
          e.id !== selected.id &&
          (e.effect.hp ?? 0) > hpChange
        );
        if (alternatives.length > 0) {
          selected = weightedRandomDraw(alternatives, finalWeights);
        }
      }
    }
  }

  // 8. 处理普通重抽
  if (selected && skillMod.rerollChance > 0) {
    if (selected.tendency === 'negative' && Math.random() < skillMod.rerollChance) {
      const alternatives = candidates.filter(e =>
        e.id !== selected.id && e.tendency !== 'negative'
      );
      if (alternatives.length > 0) {
        selected = weightedRandomDraw(alternatives, finalWeights);
      }
    }
  }

  // 9. 从池中移除
  if (selected) {
    boardGameStore.eventPool = boardGameStore.eventPool.filter(e => e.id !== selected.id);
  }

  return {
    event: selected,
    wasRerolled: false,
    wasModified: true,
    appliedSkills: skills.map(s => s!.名称),
  };
}

/**
 * 加权随机抽取
 */
function weightedRandomDraw(
  candidates: GameEvent[],
  weights: TendencyWeights,
): GameEvent | null {
  if (candidates.length === 0) return null;
  if (candidates.length === 1) return candidates[0];

  const rolls = candidates.map(e => ({
    event: e,
    weight: weights[e.tendency],
  }));

  const total = rolls.reduce((sum, r) => sum + r.weight, 0);
  let r = Math.random() * total;

  for (const roll of rolls) {
    r -= roll.weight;
    if (r <= 0) return roll.event;
  }

  return rolls[0].event;
}

### 6.1 过程结算层技能

```typescript
// dispatchEngine.ts

/**
 * 计算技能标签的过程结算加成
 *
 * mod:派遣.hp损失减免
 * mod:派遣.sanity损失减免
 * mod:派遣.hp回复加成
 * mod:派遣.sanity回复加成
 * mod:派遣.安全撤离保底
 */
export function calculateSettlementModifiers(
  skills: Skill[],
  hpChange: number,
  sanityChange: number,
): {
  finalHpChange: number;
  finalSanityChange: number;
  safeRetreat: boolean;
} {
  let hpReduction = 0;
  let hpBonus = 0;
  let sanityReduction = 0;
  let sanityBonus = 0;
  let safeRetreat = false;

  for (const skill of skills) {
    for (const mod of skill.效果) {
      switch (mod.键) {
        case 'hp减免':
          if (hpChange < 0) {
            hpReduction += mod.值 / 100;
          }
          break;

        case 'hp回复加成':
          if (hpChange > 0) {
            hpBonus += mod.值 / 100;
          }
          break;

        case 'sanity减免':
          if (sanityChange < 0) {
            sanityReduction += mod.值 / 100;
          }
          break;

        case 'sanity回复加成':
          if (sanityChange > 0) {
            sanityBonus += mod.值 / 100;
          }
          break;

        case '安全撤离':
          safeRetreat = true;
          break;
      }
    }
  }

  // 应用修正
  let finalHpChange = hpChange;
  if (hpChange < 0) {
    finalHpChange = Math.round(hpChange * (1 - hpReduction));
  } else if (hpChange > 0) {
    finalHpChange = Math.round(hpChange * (1 + hpBonus));
  }

  let finalSanityChange = sanityChange;
  if (sanityChange < 0) {
    finalSanityChange = Math.round(sanityChange * (1 - sanityReduction));
  } else if (sanityChange > 0) {
    finalSanityChange = Math.round(sanityChange * (1 + sanityBonus));
  }

  return { finalHpChange, finalSanityChange, safeRetreat };
}

/**
 * 应用社交属性修正
 *
 * 社交：提高 Hp/Sanity 回复效率
 */
export function applySocialModifier(
  hpChange: number,
  sanityChange: number,
  social: number,
): {
  hpChange: number;
  sanityChange: number;
} {
  // 社交每点增加 5% 回复效率
  const socialMod = 1 + (social - 3) * 0.05;

  return {
    hpChange: Math.round(hpChange * socialMod),
    sanityChange: Math.round(sanityChange * socialMod),
  };
}

/**
 * 应用完整的事件效果修正
 */
export function applyEventEffectModifiers(
  effect: EventEffect,
  roleId: string,
): {
  effect: EventEffect;
  appliedSkills: string[];
  socialModifier: boolean;
} {
  const role = getRole(roleId);
  if (!role) {
    return { effect, appliedSkills: [], socialModifier: false };
  }

  const skills = role.已装备技能.map(id => getSkill(id)).filter(Boolean);

  // 1. 技能过程结算修正
  const skillMod = calculateSettlementModifiers(
    skills,
    effect.hp ?? 0,
    effect.sanity ?? 0,
  );

  // 2. 社交属性修正
  const socialMod = applySocialModifier(
    skillMod.finalHpChange,
    skillMod.finalSanityChange,
    role.属性.社交,

  return {
    effect: {
      hp: socialMod.hpChange !== 0 ? socialMod.hpChange : undefined,
      sanity: socialMod.sanityChange !== 0 ? socialMod.sanityChange : undefined,
      transfer: effect.transfer,
      message: effect.message,
    },
    appliedSkills: skills.map(s => s!.名称),
    socialModifier: role.属性.社交 !== 3,
  };
}

```typescript
// settlement.ts

/**
 * 计算终点结算收益
 *
 * 金币计算公式：
 * - success（成功到达终点）：基础 300 + 每个事件 ×70 + 战斗金币加成
 * - forced（HP/Sanity 归零）：基础 120 + 每个事件 ×35 + 战斗金币加成（按 success 比例缩放）
 * - 技能「金币加成」：最终金币 ×(1 + 技能%)
 *
 * 纪念品数量（保证稀有性）：
 * - success：10% 概率获得 1 个纪念品（纯随机）
 * - forced：10% 概率获得 1 个纪念品
 * - 战斗掉落：由怪物模板的 lootChance 决定
 * - 技能「纪念品基础」：直接增加纪念品数量
 *
 * 所有数值最终四舍五入取整
 */
function calculateRewards(
  type: SettlementType,
  context: SettlementContext,
  rng: () => number = Math.random,
): { gold: number; souvenirCount: number } {
  const role = getRole(context.roleName);
  const skills = role?.已装备技能.map(id => getSkill(id)).filter(Boolean) ?? [];
  const battleReward = context.battleReward;

  // ── 基础收益 ────────────────────────────────────────────────────────
  let baseGold: number;

  switch (type) {
    case 'success':
      // 成功到达终点：基础 300 + 每个事件 ×70 + 战斗加成
      baseGold = 300 + context.eventLog.length * 70 + battleReward.goldBonus;
      break;
    case 'forced':
      // 强制结算：基础 120 + 每个事件 ×35 + 战斗加成（按 success 比例缩放）
      baseGold = 120 + context.eventLog.length * 35 + battleReward.goldBonus;
      break;
    default:
      baseGold = 0;
  }

  // ── 纪念品计算（稀有性保证）───────────────────────────────────────
  let extraSouvenirBonus = 0;

  // 计算技能加成
  for (const skill of skills) {
    for (const mod of skill.效果) {
      if (mod.键 === '纪念品基础') {
        extraSouvenirBonus += mod.值;  // 直接加纪念品数量
      }
    }
  }

  // 纪念品来源
  let baseSouvenirs = 0;
  let battleSouvenirs = 0;

  // 1. 基础纪念品（纯随机 10%）
  if ((type === 'success' || type === 'forced') && rng() < 0.1) {
    baseSouvenirs = 1;
  }

  // 2. 战斗掉落（由怪物的 lootChance 决定）
  battleSouvenirs = battleReward.lootCount;

  // ── 技能加成 ────────────────────────────────────────────────────────
  let goldMultiplier = 1;
  let protectEmpty = false;

  for (const skill of skills) {
    for (const mod of skill.效果) {
      switch (mod.键) {
        case '金币加成':
          goldMultiplier += mod.值 / 100;  // 例如 +15% → 1.15
          break;
        case '空手保护':
          protectEmpty = true;
          break;
      }
    }
  }

  // ── 计算最终值（四舍五入取整）───────────────────────────────────────
  let gold = Math.round(baseGold * goldMultiplier);
  let totalSouvenirs = baseSouvenirs + battleSouvenirs + extraSouvenirBonus;

  // 空手而归保护：至少获得 10 金币和 1 个纪念品
  if (protectEmpty && gold < 10 && totalSouvenirs === 0) {
    gold = 10;
    totalSouvenirs = 1;
  }

  return {
    gold,
    souvenirCount: totalSouvenirs,
  };
}
```

/**
 * 解析 AI 返回的故事和纪念品
 */
function parseStoryResponse(response: string, expectedCount: number): StoryData {
  const storyMatch = response.match(/<story>([\s\S]*?)<\/story>/i);
  const souvenirsMatch = response.match(/<souvenirs>([\s\S]*?)<\/souvenirs>/i);

  const story = storyMatch ? storyMatch[1].trim() : '你的废土之旅结束了。';

  let souvenirNames: string[];
  if (souvenirsMatch) {
    souvenirNames = souvenirsMatch[1]
      .split('\n')
      .map(s => s.trim())
      .filter(s => s.length > 0);
  } else {
    souvenirNames = generateDefaultSouvenirs(expectedCount);
  }

  return { story, souvenirNames };
}

/**
 * 生成默认纪念品（当 AI 生成失败时）
 */
function generateDefaultSouvenirs(count: number): string[] {
  const pool = [
    '破损的怀表', '锈蚀的徽章', '褪色的照片', '碎裂的眼镜',
    '旧世界的硬币', '生锈的钥匙', '发黄的信件', '破损的玩偶',
  ];
  const result: string[] = [];
  for (let i = 0; i < count; i++) {
    result.push(pool[Math.floor(Math.random() * pool.length)] ?? '未知的废土遗物');
  }
  return result;
}

function selectEvent(event: GameEvent) {
  if (phase.value !== 'event') return;

  // 应用角色/技能修正
  const dispatchActive = getDispatchActive();
  let finalEffect = event.effect;
  let appliedSkills: string[] = [];

      event,

      stats.value.sanity - sanityBefore

## 附录 C：数值设计问题标注

> 以下是数值评估中发现的设计问题，需要在实现前确认或修正。

### C.1 险胜的精神惩罚过重

**位置**：`battleConfig.ts` 第 1176 行

```typescript
// 险胜：基础奖励，无战利品
const sanityChange = -Math.round(monster.mentalDamage * 0.6);
```

**问题**：险胜时的精神伤害固定为 `monster.mentalDamage × 60%`，而战败时是 `monster.mentalDamage × (80%~120%)` 平均约 100%。险胜的精神惩罚反而更重，这不符合直觉。

**示例**：

- 辐射幽灵（难度 3）：mentalDamage = 35，险胜扣 21 点精神，战败平均扣 35 点
- 疯狂的神谕者（难度 5）：mentalDamage = 50，险胜扣 30 点精神，战败平均扣 50 点

**建议修正**：险胜的精神伤害改为随机或固定较低值。

```typescript
// 修正方案一：随机 30%~60%
const sanityChange = rng() < 0.5
  ? -Math.round(monster.mentalDamage * (0.3 + rng() * 0.3))
  : 0;  // 50% 概率不受精神伤害

// 修正方案二：固定 40%
const sanityChange = -Math.round(monster.mentalDamage * 0.4);
```

### C.2 险胜再战阈值过高

**位置**：`battleConfig.ts` 第 1065 行

```typescript
if (winRate >= 70) {
  return 'narrow_escape';
}
```

**问题**：标准角色（运气=3）再战胜率 `calculateRetryWinRate` 期望值约为 50 + 3×5 = **65**，远低于 70 阈值。这意味着标准角色初始失败后再战，几乎必然战败（因为 roll 均匀分布 0~100，平均 50，加上 luckBonus=15，期望 65）。

满配角色（运气=5）：luckBonus = 25，期望 = 75，才能稳定险胜。

**建议修正**：将阈值降至 **60~65**，让标准角色也有约 30%~40% 的险胜概率。

### C.3 encounter 趋向中性的上限在归一化后会失效

**位置**：`dispatchEngine.ts` 第 1600 行

```typescript
case 'encounter趋向中性':
  result.tendencyWeights.neutral = Math.min(0.6, ...);
```

**问题**：归一化在 `calculateAttributeModifiers` 和 `calculateSkillTendencyModifiers` 之后执行。当 negative 和 positive 各自被减去 `mod.值/200` 后，total 变小，归一化会放大 neutral 的占比。

**示例**：encounter 格子，智慧=3 基准 + 一个值=50 的技能：

- neutral = min(0.6, 0.333 + 0.5) = **0.6**
- negative = max(0.1, 0.333 - 0.25) = **0.083**
- positive = max(0.1, 0.333 - 0.25) = **0.083**
- total = 0.766
- 归一化后 neutral = 0.6 / 0.766 ≈ **78.3%**（远超 60% 上限！）

**建议修正**：在归一化前检查 `neutral / total` 是否超过上限，如超过则额外调整：

```typescript
// 归一化
const total = mod.negative + mod.neutral + mod.positive;
if (mod.neutral / total > 0.6) {
  const excess = mod.neutral / total - 0.6;
  const compress = excess * total;
  mod.negative = Math.max(0.1, mod.negative - compress / 2);
  mod.positive = Math.max(0.1, mod.positive - compress / 2);
  mod.neutral = 0.6 * total;
}
mod.negative /= total;
mod.neutral /= total;
mod.positive /= total;
```

### C.4 双层取整可能引入微小偏差

**位置**：`dispatchEngine.ts` 第 1768~1855 行（技能修正层 + 社交修正层）

**问题**：HP/Sanity 的修正链为：技能修正层 `Math.round()` → 社交修正层 `Math.round()`，双重取整。由于 JS 的 `Math.round(-0.5) = 0`（向正无穷截断），在某些边界情况下可能产生非预期结果。

**示例**：

- hpChange = -5，社交=5（+10%），无技能修正
- 技能层：`finalHpChange = -5`（无修正，直接返回）
- 社交层：`Math.round(-5 × 1.10) = Math.round(-5.5) = -5`（JS: -5.5 向正无穷 → -5）
- 结果：-5 → -5，无额外损失

唯一有问题的是正好 -0.5 的情况（hpChange = -5，social=5，hpReduction = 0.5）：

- 技能层：`Math.round(-5 × 0.5) = Math.round(-2.5) = -2`（JS: -2.5 → -2）
- 社交层：`Math.round(-2 × 1.10) = Math.round(-2.2) = -2`，无问题

**建议**：这是 JS `Math.round` 的标准行为，对玩家有利（负数向 0 方向舍入），可接受。如果要消除偏差，可以只在最外层取整，修正链中间步骤使用浮点数。
