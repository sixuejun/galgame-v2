# 角色系统扫描器触发机制

本文档定义角色系统扫描器的触发时机与实现逻辑，参考 `参考/酒馆助手脚本-物品栏.json` 的事件监听机制。

**前置文档**：`docs/角色系统详细设计.md` §5 扫描引擎

---

## 1. 事件监听体系

角色扫描器通过监听酒馆事件（`tavern_events`）触发扫描。扫描分为两种模式：

| 模式 | 触发时机 | 扫描范围 | 防抖 |
|---|---|---|---|
| **增量扫描**（incremental） | 新消息到来、生成开始（有检查点时） | 仅检查点之后的新消息 | 800ms 防抖 |
| **全量扫描**（full） | 初始化、删楼、回滚、修改楼层、无检查点时 | 从第一条消息开始 | 无防抖，触发即执行 |

---

## 2. 事件监听配置

参考物品栏脚本的事件监听设计：

```typescript
// 参考酒馆助手脚本-物品栏.json 第 2740-2748 行

// 监听酒馆事件
if (typeof tavern_events === 'undefined') return;

// 新消息到来：使用增量扫描（只扫新楼层，速度快）
eventOn(tavern_events.CHARACTER_MESSAGE_RENDERED, () => scheduleScan('incremental'));

// 删楼、回滚、修改楼层：先作废检查点，再全量重扫
[tavern_events.MESSAGE_DELETED, tavern_events.MESSAGE_SWIPED, tavern_events.MESSAGE_UPDATED]
  .forEach(e => eventOn(e, () => { clearCheckpoint(); scheduleScan('full'); }));

// 生成开始时：优先走增量（有检查点时），无检查点才全量
eventOn('generation_started', () => {
  const _cp = getCheckpoint();
  if (_cp) {
    scheduleScan('incremental');
  } else {
    performScan('full');
  }
});

// 切换聊天（换角色卡）：清除所有运行时状态
eventOn(tavern_events.CHAT_CHANGED, () => {
  clearCheckpoint();
  scheduleScan('full');
});
```

## 3. 防抖机制

```typescript
let debounceTimer: ReturnType<typeof setTimeout> | null = null;

/**
 * 防抖调度：避免短时间内多次触发扫描
 */
function scheduleScan(mode: 'incremental' | 'full') {
  if (debounceTimer) clearTimeout(debounceTimer);
  debounceTimer = setTimeout(() => performScan(mode), CONFIG.debounceDelay);
}
```

> 与物品栏脚本一致：`debounceDelay` = 800ms

## 4. 扫描执行流程

```typescript
/**
 * @param mode - 'full'（全量，用于删改楼）| 'incremental'（增量，仅新消息）
 */
function performScan(mode: 'full' | 'incremental') {
  const allMessages = getChatMessages();  // 获取所有消息

  let scanFromIndex = 0;

  // ── 增量扫描：确定起点，并从检查点恢复初始状态 ──────────────────────
  if (mode === 'incremental') {
    const checkpoint = getCheckpoint();

    if (checkpoint && checkpoint.message_id != null) {
      const cpMsgId = checkpoint.message_id;
      scanFromIndex = allMessages.findIndex(m => m.message_id > cpMsgId);
      if (scanFromIndex === -1) {
        // 没有新消息，提前返回
        return;
      }

      // 从检查点快照恢复已处理的数据
      Object.assign(roleDbMap, checkpoint.db_map);
      roleMaxId = checkpoint.max_id;
    } else {
      // 没有检查点，退化为全量扫描
      mode = 'full';
      scanFromIndex = 0;
    }
  }

  // ── 全量扫描：重置状态 ───────────────────────────────────────────────
  if (mode === 'full') {
    roleDbMap = {};
    roles = {};
    roleMaxId = 0;
  }

  // ── 扫描循环 ────────────────────────────────────────────────────────
  const messagesToScan = allMessages.slice(scanFromIndex);
  for (const msg of messagesToScan) {
    scanMessage(msg);
  }

  // ── 保存检查点 ──────────────────────────────────────────────────────
  if (shouldSaveCheckpoint()) {
    saveCheckpoint();
  }
}
```

## 5. 检查点机制

检查点保存扫描进度，避免每次全量扫描：

```typescript
interface 角色检查点 {
  message_id: number;  // 已扫描到的最后一条消息 ID
  max_id: number;      // 检查点时的最大角色序号
  db_map: Record<string, 角色>;  // 检查点时的角色字典快照
}

/**
 * 保存检查点
 */
function saveCheckpoint(cp?: Partial<角色检查点>): void {
  const allMessages = getChatMessages();
  const latestMsg = allMessages[allMessages.length - 1];

  const checkpoint: 角色检查点 = {
    message_id: latestMsg?.message_id ?? 0,
    max_id: roleMaxId,
    db_map: { ...roleDbMap },
    ...cp,
  };

  replaceVariables({ role_checkpoint: checkpoint }, { type: 'chat' });
}

/**
 * 作废检查点（删楼后调用）
 */
function clearCheckpoint(): void {
  replaceVariables({ role_checkpoint: null }, { type: 'chat' });
}

/**
 * 是否需要保存检查点
 * - 每次全量扫描后保存
 * - 每隔 N 条消息（checkpointInterval = 25）增量扫描后保存
 */
function shouldSaveCheckpoint(): boolean {
  const checkpoint = getCheckpoint();
  if (!checkpoint || checkpoint.message_id == null) return true;

  const allMessages = getChatMessages();
  const latestId = allMessages[allMessages.length - 1]?.message_id ?? 0;
  return (latestId - checkpoint.message_id) >= CONFIG.checkpointInterval;
}
```

## 6. 初始化流程

```typescript
$(() => {
  // 1. 尝试增量扫描（有检查点时快）
  const checkpoint = getCheckpoint();
  if (checkpoint && checkpoint.message_id != null) {
    scheduleScan('incremental');
  } else {
    // 2. 无检查点，执行全量扫描
    performScan('full');
  }

  // 3. 监听酒馆事件
  if (typeof tavern_events !== 'undefined') {
    eventOn(tavern_events.CHARACTER_MESSAGE_RENDERED, () => scheduleScan('incremental'));

    [tavern_events.MESSAGE_DELETED, tavern_events.MESSAGE_SWIPED, tavern_events.MESSAGE_UPDATED]
      .forEach(e => eventOn(e, () => { clearCheckpoint(); scheduleScan('full'); }));

    eventOn('generation_started', () => {
      const _cp = getCheckpoint();
      scheduleScan(_cp ? 'incremental' : 'full');
    });

    eventOn(tavern_events.CHAT_CHANGED, () => {
      clearCheckpoint();
      scheduleScan('full');
    });
  }
});
```

## 8. 扫描优先级

当多个事件同时触发时：

1. `MESSAGE_DELETED / MESSAGE_SWIPED / MESSAGE_UPDATED` → 全量扫描（先 `clearCheckpoint`）
2. `generation_started` → 有检查点走增量，无检查点走全量
3. `CHARACTER_MESSAGE_RENDERED` → 增量扫描（防抖）
4. `CHAT_CHANGED` → 全量扫描（清除所有状态）

防抖 timer 会被更高优先级的同步调用（`clearCheckpoint` + `performScan`）打断并立即执行。
