# 工坊 v2：弹幕文本模板库（草案）

> 用途：集中维护工坊订单的弹幕文本模板。
>
> 约定：
>
>- 模板文本可以包含槽位：`{name}`（角色名）、`{order}`（订单标题/简称）、`{work}`（工种：冶炼/制药/改装）、`<user>`（玩家名）。
>- 模板按「类型」分组，组内可再按「工种」细分。
>- 每条模板可选带一个"效果前缀"，用于调试与显示具体变化。
>
> 效果前缀（建议口径）：
>
>- （无前缀）：纯展示，不产生任何效果。
>- `进度+N`：正向增加进度秒（例如 `进度+3`）。
>- `进度-N`：负向减少进度秒（例如 `进度-5`）。
>- `灵感+N`：大正向增加进度秒（例如 `灵感+10`）。
>- `疲劳+1`：订单内疲劳 +1。
>- `加班`：开启/维持加班中。
>- `失败`：触发失败（一般搭配"扣进度+疲劳+失败"的组合）。
>
> 属性关联（建议）：
>
>- "趣味展示类"弹幕按角色属性调权：某些属性高的角色更容易触发对应的展示弹幕（但不影响数值）。
